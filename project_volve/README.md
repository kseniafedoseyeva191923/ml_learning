# Классификация литологии по каротажным данным

Учебный проект по классификации литологических интервалов в трёх скважинах A10, A15 и A16. Модель использует каротажные признаки и проверяется на отдельной скважине, которая целиком не участвует в обучении.

## Задача

Предсказать рабочий геологический тип интервала:

- `clay` — глинистый интервал;
- `siltstone` — промежуточный алевролитовый интервал;
- `sandstone` — песчаник по рабочей интерпретации. Нефтенасыщенными считаются только отдельные интервалы, прошедшие дополнительное петрофизическое правило.

В исходных LAS-файлах классы `LITH` записаны числами. Их кодировка различается между скважинами, поэтому перед обучением создан столбец `LITH_GEO` с общей рабочей интерпретацией:

```text
A10: 1 -> clay, 2 -> siltstone, 3 -> sandstone
A15: 0 -> clay, 1 и 2 -> siltstone, 3 -> sandstone
A16: 2 -> clay, 1 -> siltstone, 3 -> sandstone
```

Эта интерпретация сделана по статистике каротажных кривых. В исходных данных отдельной легенды для числовых кодов не найдено, поэтому соответствия нужно считать рабочей гипотезой.

## Данные и признаки

Используются LAS-файлы из `project_A15/data`:

- A10: 1835 исходных строк;
- A15: 552 исходные строки;
- A16: 701 исходная строка.

Технические значения `-999.25` заменяются на `NaN`, затем удаляются строки с пропусками. После очистки остаётся 1827 строк для A10, 547 для A15 и 697 для A16.

Признаки модели:

- `GAMMA` — гамма-каротаж;
- `RESISTIVITY` — электрическое сопротивление;
- `PERM` — проницаемость;
- `POROSITY` — пористость.

## Обучение и проверка

Данные разделены по целым скважинам:

- обучение: A15 и A16;
- финальная проверка: A10.

Такое разделение не смешивает соседние глубины одной скважины между обучением и тестом. Из-за небольшого количества доступных скважин кросс-валидация и надёжный подбор гиперпараметров в проект не включены.

Сравниваются:

- дерево решений `DecisionTreeClassifier`;
- случайный лес `RandomForestClassifier`.

Используются `Accuracy`, `Macro-F1` и `classification_report`.

## Результаты на A10

| Модель | Accuracy | Macro-F1 |
|---|---:|---:|
| Дерево решений | 0.7411 | 0.5282 |
| Случайный лес | 0.6962 | 0.5013 |

Песчаники распознаются устойчиво, промежуточные интервалы распознаются средне, а глинистые интервалы на A10 модель почти не находит. Это показывает, что распределения каротажных кривых заметно различаются между скважинами.

## Дополнительная разметка коллектора

В скрипте также рассчитывается `TYPE` по простым петрофизическим условиям на основе `GAMMA`, `RESISTIVITY`, `POROSITY` и `PERM`. Эта разметка используется для анализа и визуализации, но не подаётся в модель как целевой класс.

## Визуализация

Скрипт строит каротажный планшет для A10. Зелёным выделяется выполнение условия отдельной кривой, фиолетовым — совпадение всех трёх условий, штриховой оранжевой заливкой — потенциально нефтенасыщенный интервал по правилу `TYPE`.

## Запуск

Из папки `project_volve`:

```bash
python project_lithology.py
```

Зависимости проекта: `lasio`, `numpy`, `pandas`, `matplotlib`, `scikit-learn`.

## Ограничения

- доступно только три размеченные скважины;
- геологическое соответствие числовых кодов восстановлено по статистике кривых и требует подтверждения исходной легендой;
- класс `LITH = 3` в A10 интерпретируется как песчаник; из 1021 строк этого класса 18 проходят проверочное правило потенциально нефтенасыщенного коллектора;
- A15 содержит всего 6 строк, отнесённых к `sandstone`;
- результаты нельзя обобщать на другие месторождения без дополнительной проверки.
